## 후속 사용자 결정의 처리 기준

- 홈은 등록 기기의 `온라인`·`오프라인`을 표시한다. 상태 조회 실패는 오프라인으로 단정하지 않는다.
- 위험 상세에서 이미지·위치가 누락되거나 로딩에 실패하면 해당 항목을 안내하고 확인 가능한 정보는 유지한다.
- 보호자가 `직접 제거 완료`를 선택해도 즉시 완료 처리하지 않는다. 기기가 위험물 부재를 재확인한 뒤에만 `처리 완료`를 저장하고 운행을 재개한다. 잔존·재확인 실패 시 정지를 유지한다.
- 월간 리포트는 TKS_007의 실제 직접 제거·안전 위치 이동 이력을 `안전 처리 내역`으로 제공한다. 미완료·결과 미확정은 완료 건수에서 제외한다.

나머지 기능을 임의로 축소하거나 추가하지 않았다. 기존 보안·개인정보·접근성·복구 등의 보완 항목은 첨부 요구와 구분한 검토 후보로 유지했다. 단계 자동 전환·이력 저장은 첨부의 정확성 요구와 월간 변화 리포트를 구현하기 위한 연결 기능이다.
