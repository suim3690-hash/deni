# ThinQ Kids SafeGuard 유스케이스 명세서

> 추가 첨부 기준 8개 유스케이스 | v0.6 | 2026-09-17

## 작성 기준

**[유스케이스 명세서 Front](유스케이스%20명세서%20Front.py)의 TKS_001~TKS_007과 추가된 TKS_008을 각각 독립적으로 명세한다.** TKS_001~007의 우선순위는 ‘상’, TKS_008의 우선순위는 ‘중’이다. 이번 사용자 지시에 따라 추가 첨부를 최신 기준으로 삼는다. TKS_008의 성장 리포트 범위와 TKS_005의 위험 시 즉시 정지를 포함한다.

- 기본·대안 흐름은 원문을 따른다. 목적은 해당 기능과 종료 조건을 요약한다.
- **[검토 후보]**는 요청에 따라 추가한 권한·실패 대응이며 원문의 확정 정책이 아니다. **[조건부 후보]**는 해당 외부 API를 실제 사용하는 경우에만 적용한다. 공급자·연동 방식을 가정하지 않는다.
- 액터는 보호자·드니로 구분한다. 시스템은 내부 처리 주체이며 흐름 표의 ‘시스템 반응’으로 표현한다.
- 사전·사후 조건의 참조 ID는 해당 기능에 맞게 정정한다. 선행조건을 의미하는 `«include»` 표기는 제거하며 기능을 합치거나 ID를 재발급하지 않는다.
- 관련 요구사항 ID는 추가 첨부의 AD·UU 체계를 따른다. 첨부 내 중복·불일치 항목은 마지막 확인표에 별도로 남긴다.
- 2026-09-17 후속 사용자 결정에 따라 세 성장단계의 경계와 지원 범위 밖 대안, 홈의 연결 상태 표시, 위험 상세의 부분 정보 안내, 직접 제거 후 위험물 재확인·운행 재개, 리포트의 실제 안전 처리 내역을 현재 구현 기준으로 삼는다.

| 항목 | 내용 |
| --- | --- |
| 1. 유스케이스 ID | TKS_001 |
| 2. 유스케이스명 | 드니 기기 연결 상태 확인 |
| 3. 액터 | 보호자, 드니 |
| 4. 목적 | 보호자가 홈에서 현재 기기 연결 상태를 확인한다. |
| 5. 사전 조건 | 드니 기기가 사용자 계정에 등록되어 있다. |
| 6. 사후 조건 | 온라인 또는 오프라인 상태가 정상 표시된다. 오프라인이면 안내 및 Safety Care 실시간 기능 제한이 적용된다. |

### 7. 기본 흐름

| 단계 | 사용자·기기 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | 보호자가 앱 홈에 진입한다. | 등록된 드니의 연결 상태를 확인한다. |

### 8. 대안 흐름

드니와 통신이 되지 않으면 시스템은 홈에 `오프라인`으로 표시하고 `기기 연결을 확인해주세요`를 안내한다. Safety Care 실시간 기능 사용을 제한한다.

| 항목 | 내용 |
| --- | --- |
| 1. 유스케이스 ID | TKS_003 (구 UC_02) |
| 2. 유스케이스명 | 성장단계 Safety Profile 적용 |
| 3. 액터 | 사용자(보호자) |

| 5. 사전 조건 | TKS_002 완료: 아이 생년월일이 등록되어 있다. |
| 6. 사후 조건 | Safety Profile이 아이 정보에 연결·저장되고 보호자가 결과를 확인한다. |

### 7. 기본 흐름

| 단계 | 사용자 행동 | 시스템 반응 |
| --- | --- | --- |
| 1 | — | 등록된 생년월일과 현재 날짜로 개월수를 계산한다. |
| 2 | — | 개월수에 따른 성장단계를 판정한다. |
| 3 | — | 해당 단계의 Safety Profile을 아이 정보에 연결·저장한다. |
| 4 | 보호자가 적용 결과를 확인한다. | 적용 단계와 기준 요약을 표시한다. |

| 원문 구간 | 단계 | 원문 안내 문구 |
| --- | --- | --- |
| 0~12개월 | 바닥 탐색 시기 | 아기가 바닥을 탐색하기 시작하는 단계예요 |
| 12~24개월 | 걸음마 시기 | 아기가 걸음마를 시작하는 단계예요 |
| 3~7세 | 유아 활동기 | 아이의 활동 반경이 크게 넓어지는 단계예요 |

MVP 적용 경계는 각각 `0~11개월`, `12~23개월`, `36~95개월(만 3~7세)`이다. 원문 표의 세 단계 외에 프로필을 추가하지 않는다.

### 8. 대안 흐름

지원 범위 밖 대안: `24~35개월` 또는 `96개월 이상`이면 현재 지원 범위 밖임을 안내하고 임의의 Safety Profile을 적용 완료로 표시하지 않는다.

첨부 NFR-TS-001에 따른 자동 전환: 지원 단계의 월령 경계에 도달하면 시스템이 개월수·단계를 재평가하고 해당 Safety Profile로 전환한다. 전환 전후 단계·기준·적용 시점을 기록하여 TKS_008에 제공한다. 지원 범위 밖으로 넘어가면 프로필 적용을 유지·전환한 것으로 표시하지 않고 범위 밖 상태를 기록한다. 자동 평가의 실행 시점과 월령 계산의 시간대·월말·윤년 규칙은 확정이 필요하다.

직접 제거 경로의 실제 운행 재개는 후속 사용자 결정이다. 이동 경로의 자동 재개 여부는 별도 확정한다.

| FR-AD-701 | 연도·월 변경 시 재집계하고 데이터가 없는 월에는 빈 상태를 표시한다. |
| FR-UU-700 | 집계 리포트와 다음 성장단계 안전 기준 예고를 표시한다. |

첨부의 리포트 범위를 복원했다. 감지 총건수·유형별·위험도별 건수는 기존에 합의한 감지 통계의 상세 항목으로 유지한다. 회피율·청소 면적·만족도·정기 발송은 첨부에 없으므로 추가하지 않는다.

월 구분 시간대, 동일 감지 기록 중복 제외, 반복 감지 묶음 기준은 상세 정책으로 확정해야 한다. 성장단계·안전 기준 변경 이력의 저장이 필요하며 과거 월을 현재 프로필만으로 재구성하지 않는다. 첨부의 ‘안전조치 변경사항’은 후속 사용자 결정에 따라 TKS_007의 실제 제거·이동 결과를 뜻하며 화면에서는 `안전 처리 내역`으로 표시한다. 완료되지 않았거나 결과가 미확정인 처리는 완료 건수에 넣지 않는다.
