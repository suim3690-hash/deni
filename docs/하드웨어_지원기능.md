# 하드웨어 지원 기능

수동 이송 후 후진(`reverse_seconds`)과 배치 재확인 후 회전(`turnaround_seconds`)은 각각 3초다. 회전 각도는 시간 제어이므로 180도를 보장하지 않으며 실물 검증이 필요하다.

`hardware/care_runtime.py`와 현재 모델 가중치 기준이다. **코드 경로가 있음**과 **실물에서 반복 검증됨**을 구분한다. 최신 실물 확인 결과는 [통합 테스트](통합_테스트_시나리오.md)에 기록한다.

| 기능 | 코드 상태 | 실물 검증·제약 |
| --- | --- | --- |
| WebSocket 인증·상태·명령 결과 | 구현 | 백엔드·Pi와 동시 실행 재검증 필요 |
| HTTP 탐지 이미지 업로드 | 구현 | 바운딩 박스 JPEG를 물체별 이벤트로 보냄. 전송 실패 시 로컬 대기열 사용 |
| `POWER_ON`/`POWER_OFF`, `PAUSE`, `RESUME` | 구현 | 전원 의도와 실제 모터 동작을 구분. 미해결 삼킴 위험이 있으면 재개 차단 |
| 통신 단절 시 정지 | 구현 | 모터 링크 재연결 또는 백엔드 메시지 3초(`backend_timeout_seconds`) 미수신 시 주행을 `PAUSED`로 바꾸고, 복구 후에도 사용자 `RESUME` 전에는 재주행하지 않음. 이송은 `MOTOR_RECONNECTED`/`BACKEND_DISCONNECTED`로 실패 처리하고 해당 위험 차단 유지. 직접 제거 재확인은 모터 재연결 시 유지, 백엔드 단절 시 실패 |
| 삼킴 위험 자동 정지 | 구현 | 동전·구슬·배터리. 주사위는 코드에 있으나 현재 가중치에는 클래스 없음 |
| 직접 제거 `RECHECK_HAZARD` | 구현 | 명령 후 새 영상에서 해당 라벨 2초 연속 미검출 필요. 같은 라벨 물체가 남으면 실패. 성공 시 해당 라벨 알림 쿨다운을 초기화해 재등장을 즉시 새 이벤트로 올림 |
| 수동 안전 이송 `RELOCATE` | 부분 지원 | 대상 1개 확보 → 마커 추적 → 후진 → 물체·마커 근접 재확인 → 회전. 재확인용 대상 탐지는 제어에는 사용하되 새 백엔드 알림으로 올리지 않는다. 확보/후진/회전 시간과 실물 배치 조정 필요 |
| 자동 이송 모드 | 미지원 | 화면 안내용 목업. 자동 기기 명령 없음 |
| 생활공간 위험 | 구현 | 전선·콘센트 감지 이벤트 전송, 이 위험만으로는 정지하지 않음 |
| 지도 실측 좌표 | 미지원 | 탐지 API에 좌표 필드 없음. 프론트는 예시 마커 사용 |

| 데이터 | 하드웨어 → 백엔드 | 저장·표시 |
| --- | --- | --- |
| 최신 전원·작업·이동 상태 | WebSocket `ROBOT_STATE` | `robot_live_state`, 홈 5초 폴링 |
| 배터리·이동 시간·거리 | 측정 가능할 때만 상태에 포함 | 미측정은 `null`. 추정값으로 채우지 않음 |
| 탐지 ID·모델·한글 라벨·이미지 | HTTP multipart | `detection_events`; 지원 라벨은 `hazards`에도 연결 |
| 명령 접수·실행 결과 | WebSocket `COMMAND_ACK`·`COMMAND_RESULT` | `device_command_delivery`·위험 해결 판정 |

모델의 숫자형 탐지 우선순위는 성장단계별 위험도가 아니다. 위험도는 백엔드가 아이 프로필로 계산한다. 기기 자체에는 DB 비밀번호가 필요하지 않다. 자세한 실행·설정은 [하드웨어 README](../hardware/README.md)와 [통합 런타임](../hardware/CARE_RUNTIME_KO.md)을 따른다.
