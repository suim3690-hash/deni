## 3. 동작 계약

- **전원 ON** → 자동 전진 + 위험물 탐지 시작. **전원 OFF** → 모터·탐지 정지, 백엔드 통신은 유지.
- 삼킴 위험물(동전·구슬·배터리·주사위)을 보면 스스로 정지(`HAZARD_PAUSED`).
  생활 위험 요소(전선·콘센트)는 알림만 보내고 멈추지 않는다.
- 정지 상태에서 프론트가 두 가지를 요청한다.
  - `RECHECK_HAZARD`: 유효한 영상에서 대상이 **2초 연속** 미검출이면 완료.
  - `RELOCATE`: 대상을 중앙에 맞춘 뒤 마커 방향으로 밀고, 마커 fill이 기준에 닿으면 후진·회전.
- 완료는 **기기가 보고할 때만** 인정한다. `CommandResultPolicy`가 명령별 증거를 검증한다
  (재확인은 `hazardPresent=false` + 2초 이상, 이송은 `relocationCompleted`, 정지는 `PAUSED` 확인).
- 위험물 해결·`청소 재개`는 기기 결과를 받은 뒤에만 일어난다.

## 4. 기기 공유 구조

```
device_children (V10)      ← 이 기기를 쓸 수 있는 아이 목록
  robot-001 ─┬─ 김드니  2026-03-15  INFANT
             ├─ 김엘지  2024-09-15  TODDLER
             ├─ 김로니  2021-09-15  ACTIVE_CHILD
             └─ 기존 아이 (위험 기록 107건)

devices.child_id           ← 지금 이 기기의 탐지를 귀속시킬 아이 = 활성 프로필
```

- 프론트에서 프로필을 열면 `POST /devices/{id}/active-child`로 그 아이가 활성이 된다.
  **여러 창에서 서로 다른 프로필을 열면 마지막에 연 쪽으로 넘어간다.**
- 이름+생년월일이 같으면 새 아이가 생기지 않고 기존 프로필로 들어간다(`childRegistrationKey`).
- 한 아이가 여러 기기에 붙는 것은 여전히 막는다. 공유되는 쪽은 기기이지 아이가 아니다.

설정값은 `hardware/care_config.json`에서 바꾼다(도착 기준 `marker_stop_fill` 0.13126 포함).

## 7. 남은 일

1. **주사위 `dice` 가중치.** 코드 경로는 연결했지만 현재 가중치 클래스는 `object.pt`가
   battery·coin·marble, `hazard.pt`가 socket·wire뿐이라 주사위는 탐지되지 않는다.
2. **후진 1초·회전 1초는 시간값**이며 측정한 180도가 아니다. 실물에서 재고 조정해야 한다.
3. 미는 부품 제작과 카메라 가림 각도 재확인.
4. **데모 3명의 위험물 시드가 없다.** 대시보드·리포트가 0건으로 나온다. 과거 월 기록은
   업로드 API가 수신 시각을 강제하므로 DB 시드로 넣어야 한다.
5. **한 사진 여러 물체 API 미구현.** 프론트는 임시로 `activeHazards` 전체를 사진 아래 표시한다.
   백엔드가 이벤트별 물체 목록을 주면 교체해야 한다.
6. **제어 권한 분리 없음.** 심사위원용 목업 계정을 만들지 않기로 했고, 명령 API에 인증이 없다
   (Spring Security 미적용). 제어는 발표자만 조작하는 운영 규칙으로 지킨다.
7. 실제 로봇·실제 백엔드로 전원→탐지→정지→처리→재개 전 구간을 이어서 실행한 기록이 아직 없다.

## 8. 현장에서 겪은 것

- **Pi 무선이 먹통이 된 적이 있다.** `dmesg`에 `brcmf ... err=-110`이 6초마다 반복되고, ping이
  평상시 1~8ms인데 주기적으로 380~700ms 멎고 13% 손실이 났다. 모터 ACK 제한이 0.5초라 계속 끊겼다.
  **Pi 재부팅으로 해결**됐다(손실 0%, 평균 7ms). 전원·발열·혼잡·신호는 모두 정상이었다.
  재발하면 재부팅, 그래도 안 되면 랜선을 쓴다.
- Pi 화면에 세션 시작/종료가 계속 찍히는 것은 서버가 죽는 게 아니라 PC 클라이언트가 재접속하는 것이다.
- 기기 상태 보고의 약 5%가 "미래 시각"으로 조용히 버려지고 있었다. `fc9ae62`에서 고쳤다.
- `RUN_DB_TESTS=true` 없이 돌리면 DB 테스트 27개가 건너뛰어진다. 스키마를 바꿨으면 반드시 켜고 돌린다.
