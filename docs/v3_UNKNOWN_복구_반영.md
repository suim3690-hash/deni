# UNKNOWN 요청 복구

서버는 연결된 PC에 UNKNOWN 명령의 결과를 약 2초 간격으로 조회한다. 새 메시지 COMMAND_STATUS는 실행 명령이 아니며 기존 명령을 다시 실행하지 않는다.

- PC에 저장된 결과가 있으면 기존 결과와 완료 시각을 그대로 재전송한다.
- 실행 핸들러가 진행 중이면 조회는 기다린다. 모터 연결이 끊겨도 처리 작업 120초, 일반 제어 8초의 제한 시간이 적용되어 결과가 생성된다.
- 핸들러 예외로 결과가 유실되면 제어기에 남은 결과를 회수한다. 고아 작업이 남아 있으면 정지를 요청하고 다음 조회에서 정지를 확인한다.
- 결과가 없을 때는 정상 제어 루프, 정지 단계, 연결된 모터의 최근 0.25초 이내 S 응답이 모두 확인되어야 FAILED / RESULT_UNAVAILABLE로 종료한다. 위험을 완료 처리하지 않으며 기존 버튼으로 새 요청을 할 수 있다.
- 이미 시작한 명령의 중복 수신은 재실행 대신 결과 조회로 처리한다. 복구 결과는 기존 SQLite commands / pending_results에 저장하고 서버 수신 확인까지 재전송한다.

화면과 DB 스키마는 변경하지 않았다. 서버 재시작 시 기존 위험 완료 처리 정책도 유지했다. 백엔드와 PC 프로그램을 함께 업데이트해야 새 조회 프로토콜이 작동한다.

통신 단절, 오래된 모터 응답, 제어 루프 이상 등으로 결과나 정지를 확인할 수 없으면 UNKNOWN을 유지한다. 작업이 없는 상태라도 주행 중이면 정지 상태 확인 전에는 임의로 실패 처리하지 않는다.

회귀 테스트 코드를 추가했으나 이번 작업에서는 테스트·빌드·실제 로봇·DB 검증을 실행하지 않았다. 정적 검토만 수행했다.
